# Yogurt Natural Fruits

Landing page informativa desarrollada para presentar la marca
Yogurt Natural Fruits, sus sabores, beneficios, presentaciones
y medios de contacto.

## Evidencia académica

**Código:** GA10-220501097-AA6-EV01  
**Aprendiz:** Ivan Munevar  
**Programa:** Tecnología en Análisis y Desarrollo de Software  
**Institución:** Servicio Nacional de Aprendizaje SENA  

## Objetivo

Desarrollar y desplegar una página web estática mediante una
plataforma de hosting, permitiendo su consulta a través de una
dirección pública de Internet.

## Características

- Diseño adaptable a computadores, tabletas y celulares.
- Menú de navegación interactivo.
- Catálogo de seis sabores.
- Presentación de beneficios del producto.
- Botones de contacto mediante WhatsApp e Instagram.
- Información sobre el impacto social del emprendimiento.
- Dirección pública mediante hosting gratuito.

## Sabores disponibles

- Feijoa
- Fresa
- Guanábana
- Maracuyá
- Melocotón
- Mora

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Live Server
- Git y GitHub
- Netlify
